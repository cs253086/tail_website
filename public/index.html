Boot TAIL OS in QEMU

Read the full guide 
$ sudo apt-get install -y qemu-system-arm qemu-utils
$ curl -O https://tail-os.com/downloads/run_tailos_qemu.sh
$ chmod +x run_tailos_qemu.sh
$ ./run_tailos_qemu.sh

Exit with Ctrl-A, then X.
