TAIL OS is a real-time microkernel written in Rust for robotics and safety-critical systems.

< 2µsIPC latency
64 KBkernel footprint
100%safe Rust core

Boot it in about two minutes

Read the full guide 
$ sudo apt install -y qemu-system-aarch64 qemu-utils
$ ./scripts/run_tailos_qemu.sh

No toolchain and no build. The launcher caches the prebuilt kernel and data disk, then boots QEMU with the right flags.

Getting Started Run TAIL OS, set up a development environment, and build your own applications. Running TAIL OS in QEMU Boot the prebuilt image under QEMU on Ubuntu with a single command. Installing on Raspberry Pi 3 Flash the SD card image, wire the serial console, and boot on real hardware.
